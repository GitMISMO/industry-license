# industry-license
Industry License HQ: the yearly industry licensing list for technology and service providers, with the
evidence and scoring behind it (still in business, uses MISMO standards), quotations and tracking.
Live at https://resources.mismo.org/industry-license/ (sign-in required).

Set up the same way as IIF Planning HQ and Member 360. The data lives in the private `industry-license-data` repo
and is saved through the resources.mismo.org relay under the project key `industry-license`. No token, secret or
company data is ever kept in this repo.
